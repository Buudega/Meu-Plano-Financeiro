# Meu Plano Financeiro

App estático para registrar despesas, planejar contas, metas de poupança e viagens.

## Publicação no GitHub Pages

Publique `index.html`, `manifest.webmanifest`, `service-worker.js` e os arquivos de ícone na raiz do projeto do GitHub Pages.

## Armazenamento

O app salva os dados automaticamente no armazenamento local do navegador e os carrega ao abrir novamente no mesmo navegador e aparelho. Os dados não são sincronizados entre dispositivos. Use **Exportar backup** nas configurações para manter uma cópia.
