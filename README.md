# Meu Plano Financeiro

App estático para registrar despesas, planejar contas, metas de poupança e viagens.

## Publicação no GitHub Pages

Publique `index.html`, `manifest.webmanifest`, `service-worker.js` e os ícones na raiz do projeto do GitHub Pages.

## Armazenamento

O app não pede senha. Os dados ficam no armazenamento local do navegador e não são sincronizados entre dispositivos. Use **Exportar backup** nas configurações para salvar uma cópia dos dados.
