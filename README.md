# Meu Plano Financeiro

App estático para controlar despesas, planejar contas, metas de poupança e viagens. Inclui suporte básico a instalação como PWA.

## Arquivos para o GitHub Pages

Publique todos estes itens na raiz do repositório:

- `index.html`
- `manifest.webmanifest`
- `service-worker.js`
- pasta `icons/`

Depois, no Android com Chrome, abra o endereço do projeto e use **⋮ → Instalar app** (ou **Adicionar à tela inicial**).

Os dados ficam no armazenamento local do navegador. A cópia instalada pode manter dados próprios; use o backup do app antes de limpar os dados do site ou do navegador.
